## Nebius Token Factory (as of 23 Oct 2026)

**API.** Base URL `https://api.tokenfactory.nebius.com/v1/`, Bearer `NEBIUS_API_KEY`, used straight from the official OpenAI Python and JS SDKs via `base_url` (verified in docs quickstart). Regional base URLs also exist (`api.tokenfactory.{eu-west1,us-central1,us-north1,uk-south1,…}.nebius.com/v1/`, seen in the console bundle); public serverless models are "Global" region and may move. Live OpenAPI (`https://api.tokenfactory.nebius.com/openapi.json`, version 20261022) exposes `/v1/chat/completions`, `/v1/completions`, `/v1/embeddings`, `/v1/rerank`, `/v1/responses`, `/v1/models` (`?verbose=true` returns context, pricing and per-model TPM/RPM), `/v1/files`, `/v1/fine_tuning/jobs`, `/v0/dedicated_endpoints`, `/v1/datasets`. **No `/v1/batches` path in the spec**: the cookbook `batch.ipynb` uses `client.files.create(purpose="batch")` + `client.batches.create(endpoint="/v1/chat/completions", completion_window="24h")` and warns it "may require project enablement". Treat batch as not demo-critical.

**Chat completions features (verified in the API reference):** content parts `text`, `image_url` (URL or base64 data URI, max 13.98M chars, `detail` auto/low/high) and **`video_url`** (same shape); no documented cap on images per request. `response_format` `text | json_object | json_schema` (the structured-output guide says put the schema in the prompt as well; look for the "JSON mode" tag per model). `tools` (function only), `tool_choice` none/auto/required/named, `stream` + `stream_options.include_usage`, `reasoning_effort` none/minimal/low/medium/high/xhigh/max, `usage.completion_tokens_details.reasoning_tokens`, streaming `delta.reasoning_content`, `max_tokens` default 8192, `n` up to 128, `service_tier` auto/default/flex/no-limit, free-form `extra_body`. Implicit prefix caching is on for all serverless text calls (`usage.prompt_tokens_details.cached_tokens`, per-model cached input price). Responses API (`/v1/responses`) exists with `input_image` items; video items not confirmed there.

**Rate limits.** Dynamic, per project: docs' illustrative baseline 60 RPM / 400k TPM, auto +20% per 15-min window when usage ≥80%, down ÷1.5 when ≤50%, ceiling 20× base; 429 + `Retry-After`; headers `x-ratelimit-remaining-requests/tokens`; over-limit requests may still be served with `x-ratelimit-over-limit: yes`. Real defaults are shown in the dashboard. Model-level caps are published in `/v1/models?verbose=true` (example model: 800k TPM / 1,200 RPM).

**Catalog.** Authoritative machine-readable source: `https://tokenfactory.nebius.com/api/public/models_info` (30 public models today; every flavor labelled `cheap`, no `-fast` flavors currently listed). Prices are USD per 1M tokens.

## Nebius AI Cloud: Serverless AI

Three deployment types (docs call the third **Devlab**; the hackathon copy says DevPod): **Job** (runs to completion, no URL), **Endpoint** (serves HTTPS requests until stopped), **Devlab** (IDE/notebook). Provide any container image; billing is per second at Compute VM + disk rates (no serverless-specific price list): L40S $1.35/GPU-h, H100 $4.50, H200 $5.40, B200 $8.50, B300 $9.50 (GPU only; vCPU/RAM extra; preemptible = spot). Default quotas in eu-north1: 32 H100, 32 H200, 32 L40S, 12 VMs; us-central1 starts at 0 GPUs. AI Cloud sign-up: Google/GitHub/Microsoft login, billing requested at first resource, $25 charged to the card and credited to balance.

**Jobs.** `nebius ai job create --name X --image IMG --container-command bash --args "-c ..." --platform gpu-l40s-a --preset 1gpu-8vcpu-32gb --timeout 2h [--env k=v] [--env-secret] [--inject-file local:/path (64 KiB)] [--volume "s3://bucket:/data:rw" | bucket-id:/data] [--disk-size 250Gi] [--preemptible --restart-policy on-failure]`. Timeout 1h–168h (default 24h). REST: `POST https://api.nebius.cloud/ai/v1/jobs` with `Authorization: Bearer <IAM token>` and `spec.{image,containerCommand,args,platform,preset,timeout,subnetId,disk}`; status via `GET /ai/v1/jobs/{id}` (`status.state` → COMPLETED). Logs only in console/CLI (`nebius ai job logs ID --follow`), not via REST. Jobs cannot be stopped, only cancelled/deleted. Q3-2026 release notes say Python files can now be submitted without a container (not yet in the manage page). Queue time is not documented; the Cosmos templates report ~8 min startup on preemptible RTX 6000.

**Launching from a web app:** yes, via REST with an IAM token (12 h lifetime, `nebius iam get-access-token`) or the SDKs: Python `pip install nebius` (reads `NEBIUS_IAM_TOKEN` or service-account key file), JS `npm install @nebius/js-sdk` (Node 22/24/25; `CredentialsFileReader` does JWT→IAM exchange and refresh in the background). The docs do not show an `ai/v1` client in the SDK examples; the REST path is verified.

**Endpoints.** `nebius ai endpoint create --image vllm/vllm-openai:v0.18.0-cu130 --container-command ... --platform gpu-l40s-a --preset 1gpu-8vcpu-32gb --public --container-port 8000 --auth token --token $T --shm-size 16Gi --subnet-id ...`; managed HTTPS URL, ~5 min to RUNNING, 120 Mbps / 300 new conn/s per endpoint, config immutable after creation, no documented autoscaling or scale-to-zero (stop/start exists; stopped endpoint costs nothing). **Custom vLLM models: yes, verified**: the vLLM tutorial pulls any HF model; the serverless-ai-cookbook has a 1-click **Cosmos 3 Reasoner** template (`nvidia/Cosmos3-Nano`, 16B omnimodal, `vllm/vllm-openai:v0.29.0`, `gpu-h100-sxm 1gpu-16vcpu-200gb`, 500 GiB disk, ~15 min to first answer, OpenAI-compatible `/v1/chat/completions` with `video_url`, `extra_body={"media_io_kwargs": {"video": {"fps": 4, "num_frames": -1}}}`, reasoning by adding `<think>` to the prompt; validated cheaper on `gpu-rtx6000-a` in uk-south2; `Cosmos3-Edge` 4B runs on L40S in ~7 min). Also Cosmos 3 Generator (vllm-omni, video generation), a Cosmos 3 Synthetic Data job (~6 min per 7.9 s 720p clip on RTX 6000) and Cosmos 3 SFT (8×H100). No Nemotron, Isaac, MuJoCo or LeRobot templates. Nebius also open-sourced a Physical AI Workbench (`github.com/nebius/nebius-physical-ai`, Apache-2.0, 21 Oct 2026) with Cosmos 3, Isaac Lab, MJLab, Reachy2+LeRobot, Franka+Genesis, G1+SONIC workflows, but it runs on Nebius Kubernetes via SkyPilot, not Serverless.

## Tavily

`POST https://api.tavily.com/search|extract|crawl|map|research`, `Authorization: Bearer tvly-…`. Search params: `query`, `search_depth` basic/advanced/fast/ultra-fast, `max_results` ≤20, `topic`, `time_range`, `include_answer`, `include_raw_content`, `include_domains` (≤300) with `include_domains_mode` restrict/prefer, `include_usage`. Response: `{query, answer?, results[{title,url,content,score,raw_content?,published_date?}], response_time, usage.credits, request_id}`. Extract: `urls` (1–20), `query` + `chunks_per_source` rerank, `extract_depth`, `format` markdown/text; returns `results[{url,raw_content}]` + `failed_results`. Crawl: `url`, `instructions`, `max_depth` ≤5, `limit`; mapping 1 credit/10 pages + extraction 1 credit/5 pages. Costs: search 1 (advanced 2) credit; extract basic 1 per 5 URLs. Free Researcher plan: 1,000 credits/month, no card; PAYG $0.008/credit; dev keys 100 RPM. JS SDK `@tavily/core` (`tavily({apiKey}).search(q)` / `.extract(url)`), Python `tavily-python`. Keyless access to Search/Extract exists for trials.

## Recommendations
- Make nvidia/Nemotron-3.5-Super-VL the single NVIDIA model on the demo-critical path: it is the only NVIDIA vision model on Token Factory, takes video_url directly (mp4 up to 2 min), supports JSON schema output, tools and reasoning, and costs $0.30/$0.90. Send keyframes as image_url and short clips as video_url from the Vercel server route; keep a text-only Nemotron (nvidia/Nemotron-3_5-Lightning at $0.06/$0.24, or nvidia/Nemotron-3-Ultra-550b-a55b for the interview if quality matters) for the conversation/spec synthesis so the pitch names two Nemotron models.
- Day 1: sign up for Token Factory (card required, $1 trial), submit the $25 promo form with code NEBIUS-DEVPOST-GLOBAL26, join the Builder Program for the second $25 plus $25 Tavily, and create a Tavily key (1,000 free credits is enough on its own). Smoke-test video_url + response_format json_schema on Nemotron-3.5-Super-VL immediately; if video_url is rejected on the shared endpoint, fall back to 8-16 keyframes as image_url.
- Drop Cosmos Reason on Token Factory (removed 31 Aug 2026). If a Cosmos critique is wanted, use the 1-click Cosmos 3 Reasoner Serverless Endpoint template (nvidia/Cosmos3-Nano on H100, ~15 min startup, ~$4.50/h plus vCPU/RAM, token auth, video_url in) and treat it as an optional teammate track: spin it up only for recording the demo, delete it after, and never put it on the live demo URL's critical path.
- Use Nebius Serverless Jobs as the batch tier for sim evaluation (MuJoCo rollouts under perturbations, or batch pose extraction) with a public container image on gpu-l40s-a 1gpu-8vcpu-32gb ($1.35/GPU-h) or cpu-d3 for MuJoCo-only work; launch from the Next.js app via REST POST https://api.nebius.cloud/ai/v1/jobs with a service-account IAM token (12 h) or @nebius/js-sdk, write results to an Object Storage bucket mounted with --volume, and poll GET /ai/v1/jobs/{id}. Keep the in-browser MuJoCo WASM replay as the always-works path and present the job as the scale-out path.
- Create AI Cloud resources in eu-north1 (default quota 32 L40S / 32 H100) rather than us-central1 (0 GPUs by default) unless using RTX 6000 in uk-south2; request quota on day one if a different region is needed, since approval time is unpublished.
- Do not use Token Factory batch or fine-tuning in the plan: batch is undocumented and may need project enablement, and no NVIDIA model is fine-tunable. Pitch the LeRobot export as GR00T fine-tune-ready and, for the Nebius story, point to the Cosmos 3 SFT / Axolotl job templates as where that training would run.
- Rely on implicit prefix caching: keep the system prompt, tool definitions and the extracted pose/token summary as a stable prefix across interview turns so Nemotron calls hit the $0.06 cached rate; include reasoning_effort explicitly (none for extraction, medium/high for spec synthesis) and check usage.completion_tokens_details.reasoning_tokens to control spend.
- Tavily bonus: one runtime tavily.search (advanced, include_domains for standards bodies and tool vendors) plus tavily.extract on the top hits, feeding the spec's preconditions and safety checks; log the request_id and credits so the README can show the real runtime call.
- Collect the Most Valuable Feedback entry as you go: note gaps found here (no video limit docs, chat_template_kwargs undocumented, no /v1/batches in the spec, no endpoint autoscaling, logs not available via REST, Devlab vs DevPod naming), which is cheap to write up and competes for 10 x $100.
